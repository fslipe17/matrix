# Labirinto em JavaScript

Neste projeto, desenvolvi um **jogo de labirinto utilizando HTML, CSS e JavaScript**.
O labirinto é construído a partir de uma **matriz 20x20**, onde os valores `1` representam as paredes e os valores `0` representam os espaços livres para movimentação.
O jogador é representado por um quadrado azul e pode se movimentar pelo labirinto utilizando as **setas do teclado**.
